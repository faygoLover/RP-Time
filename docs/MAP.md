# RP Time — карта

Версия на момент написания: 1.2.0 (16.11.2026). Факты по классам и миксинам — `docs/INDEX.md`.

## 1. Что делает и чего не делает

День и ночь любой длины (по умолчанию день 2 часа, ночь 1 час), скорость и пауза времени. Ванильные
`/time set`, кровати и часы работают. Ночь ускоряется, только когда спят все, кого надо считать. Растения и
саженцы растут по игровому времени. Часы на табличках. Замена часов из PCD.

За этим — не сюда:
- что происходит с телом, едой, сном за прошедшее время — моды-владельцы (слушают события прокрутки RP Core);
- кого считать спящим — решают моды сна и тела (`RpSleepCountEvent`), здесь только вопрос;
- команда `/rptime` для ведущего в RP Core и её «пауза времени RP» — общая: этот мод становится для Core
  источником времени (`RpCoreAPI.registerTimeSource`). **RP Core необязателен:** без него мод работает сам.

## 2. Как течёт работа

**Ход времени.** `mixin/ServerLevelTimeMixin` перехватывает продвижение времени суток → `server/TimeService`:
сколько тиков суток пройти за этот реальный тик — `core/DayCycle` (длины дня и ночи, множитель, пауза; без
Minecraft) → состояние ведущего (`server/TimeState`, мир) → клиентам `network/CyclePacket` →
`client/ClientTime` + `mixin/ClientLevelTimeMixin` (клиент идёт так же, без рывков).

**Сон.** ванильный мгновенный пропуск ночи отключён; `server/SleepService`: спят все, кого считаем (спрашивает
`RpSleepCountEvent` через `integration/CoreLink`), — ночь идёт ускоренно; за прошедшее игрокам рассылается
прокрутка (`RpTimeSkipEvent`, вышедшим — `RpTimeSkipOfflineEvent`).

**Растения.** `server/GrowthService`: культуры (`mixin/CropBlockAccess`) и саженцы (`mixin/SaplingBlockMixin`)
растут по игровым суткам, а не по случайным тикам реального времени.

**Команды.** `command/TimeCommands`: `/rptime info`, `day`, `night`, `reset` — подкоманды рядом с командой RP
Core; длительности — `core/Durations` (`2h`, `90m`).

**Часы.** `core/Clock` (0 тиков = 6:00, 1000 тиков — час); таблички — `client/SignClock` + `mixin/SignTextMixin`.

**Связь с Core.** `integration/CoreLink` (мягкий вход: проверка `isLoaded("rpcore")`) → `integration/CoreBridge`
(единственный класс с вызовами `RpCoreAPI`): регистрация источника времени, пауза, события.

## 3. Карта пакетов

| Пакет | За что отвечает | С чего начать читать |
|---|---|---|
| `rptime` | вход и конфиг | `RpTime`, `TimeConfig` |
| `core` | расчёты без Minecraft | `DayCycle`, `Clock`, `Durations` |
| `server` | ход времени, сон, рост, состояние ведущего | `TimeService`, `SleepService`, `GrowthService`, `TimeState` |
| `mixin` | время суток на сервере и клиенте, рост, таблички | `ServerLevelTimeMixin` |
| `integration` | мягкая связь с RP Core | `CoreLink`, `CoreBridge` |
| `api` | вход для других модов (сервер) | `RpTimeAPI` |
| `command` | `/rptime …` | `TimeCommands` |
| `network` | один пакет | `TimeNetwork`, `CyclePacket` |
| `client` | ход времени на клиенте, часы на табличках | `ClientTime`, `SignClock` |

## 4. Хочу добавить… — рецепты

| Что | Где | Образец | Не забыть |
|---|---|---|---|
| настройку длины, скорости, роста | `TimeConfig` (COMMON) | длины дня и ночи | если её меняет ведущий на ходу — поле в `TimeState` и в `CyclePacket` |
| команду времени | `command/TimeCommands` | `/rptime day` | длительности — `Durations` |
| новое, что должно «идти по игровому времени» | в своём моде — события прокрутки RP Core; в ванили — миксин здесь по образцу роста | `GrowthService` + `SaplingBlockMixin` | — |
| метку часов на табличке | `client/SignClock` | — | замена при отрисовке, текст таблички не меняется |
| обращение к RP Core | только в `integration/CoreBridge`, вызов — через `CoreLink` | `registerTimeSource` | иначе мод перестанет грузиться без Core |
| поле, которое должен знать клиент | `network/CyclePacket` | — | — |

## 5. Данные

| Что | Где хранится | Ключ | Что при смерти | Как попадает клиенту |
|---|---|---|---|---|
| что ведущий поменял командами (длины, множитель, пауза) | мир, `SavedData` | `rptime` | — | `CyclePacket` |

У игрока мод ничего не хранит. Имя `rptime` не менять.

## 6. Связи

- RP Core — **необязателен**: источник времени (`registerTimeSource`), пауза (`setTimeRunning`,
  `timeControlEnabled`), события `RpSleepCountEvent`, `RpTimeSkipEvent`, `RpTimeSkipOfflineEvent`.
- Другим модам: `api/RpTimeAPI`. Моды семейства о длине суток спрашивают RP Core (`dayLengthSeconds`), а не этот мод.

## 7. Конфиги

`config/rptime-common.toml` — `TimeConfig`, 11 ключей (тип COMMON: нужен до загрузки мира и на клиенте).

## 8. Сеть

Канал `rptime:main`, один пакет сервер → клиент `CyclePacket`. Клиент ничего не присылает.

## 9. Ловушки

- **Миксин во время суток уровня** задевает всё, что читает время: чужой мод с собственным пропуском ночи может
  конфликтовать. Ванильный `/time set` оставлен рабочим намеренно.
- **Клиент должен идти тем же ходом**, иначе небо дёргается при каждой синхронизации времени.
- **Классы RP Core — только в `CoreBridge`.** Вызов `RpCoreAPI` из другого класса сломает запуск без Core.
- **Пауза — общая с RP Core:** пауза времени RP останавливает и сутки; не заводить вторую.
- На живом сервере RP-время может стоять на паузе (так было оставлено) — проверять состояние, прежде чем судить о механиках.

## 10. Тесты

Игровых тестов у мода нет; расчёты `core/` проверяются в игре и тестами соседей (RP Needs: сон и время).
`python ../_family/family.py verify "RP Time"` — компиляция и связи.
